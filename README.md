# EditRush

EditRush is a fast, simple video editor for macOS and Windows, built as a drop-in replacement
for Adobe Premiere Rush. It does the everyday jobs well: cut clips together on a multi-track
timeline, add titles, fades, transforms and colour adjustments, and export an MP4 or MOV.
It launches instantly, plays and scrubs smoothly, and saves your work continuously.

| | macOS | Windows |
| --- | --- | --- |
| Source | `Sources/`, `Tests/`, `Scripts/` | `windows/` |
| Built with | Swift, SwiftUI + AppKit, AVFoundation, Core Image on Metal | Electron (HTML canvas, Web Audio) and ffmpeg |
| Requires | macOS 15 or later (Apple Silicon recommended) | Windows 10 or 11, 64-bit |

Both versions read and write the same `.editrush` project files. Shortcuts below are written
for the Mac; on Windows use Ctrl for ⌘ and Delete or Backspace for ⌫ (see
[Windows differences](#windows)).

## Build & install (macOS)

```sh
Scripts/build_app.sh            # release build → build/EditRush.app
cp -R build/EditRush.app /Applications/
```

`Scripts/build_app.sh debug` builds a debug bundle instead. To work on the code directly:

```sh
swift build                     # debug build
swift test                      # unit tests (run Scripts/make_fixtures.sh first; needs ffmpeg)
.build/debug/EditRush           # run without bundling
```

The app icon is generated by `swift Scripts/make_icon.swift` (writes `Resources/AppIcon.icns`;
pass a second path to also save a 1024 px PNG preview).

## Build & install (Windows)

Needs Node.js, plus `ffmpeg.exe`, `ffprobe.exe` and `LICENSE` from a gyan.dev "essentials"
build (7.1 or later) copied into `windows\ffmpeg\` (not in git).

```powershell
cd windows
npm install
npm start                        # run from source
npm test                         # unit tests for the editing core
npm run package                  # portable app: windows\dist\EditRush-win32-x64\EditRush.exe
.\scripts\make_fixtures.ps1      # test media into ..\Fixtures
```

`windows/README.md` has the details and the differences from the Mac version.

## Features

- **Import** MP4, MOV, MP3, WAV, OGG (Vorbis / Opus), PNG and JPG — via the Import button,
  ⌘I, dragging files from Finder (Explorer on Windows) anywhere onto the window, or opening
  them on the Dock icon (Windows: passing them to `EditRush.exe`).
- **Media bin** with poster frames, audio waveforms, duration badges, a kind filter
  (All / Video / Audio / Images), missing-file detection and relinking (right-click → Locate File…).
  Double-click an item (or use its **+** button) to append it to the main track after the playhead
  (the playhead moves to its end, so repeated adds build a sequence), or drag it to any track.
  If a missing file comes back (e.g. you reconnect the drive), its thumbnails and the preview
  reload when you switch back to EditRush.
- **Multi-track timeline**: video / overlay tracks and audio tracks, snapping, zoom, split and join,
  ripple delete, close gaps, nudge, duplicate, cut / copy / paste, detach audio.
- **Transitions**: fade up from black and fade to black, per clip.
- **Transform**: scale and move clips on the canvas.
- **Titles**: text layers with font, size, colour and placement.
- **Colour**: per-clip brightness, contrast, saturation and filters.
- **Export** at 720p, 1080p, 4K or project size, H.264 or HEVC, MP4 or MOV, with progress,
  time remaining and cancel. You can hide the export sheet and keep editing; the toolbar's
  Export button shows progress. Quitting or closing the window during an export asks first
  (Keep Exporting / Stop Export and Quit); a stopped or failed export never replaces an
  existing file.
- **Undo / redo** for every edit (the last 1000 steps).

## Projects & autosave

- A project is a single `.editrush` file (JSON). It references your media files where they
  are on disk; nothing is copied. If you move a file, the bin marks it **Missing** and you can
  relink it from the item's context menu.
- EditRush saves continuously, like Rush: 1.5 s after each change the project is written to
  `~/Library/Application Support/EditRush/Autosave.editrush` (Windows:
  `%APPDATA%\EditRush\Autosave.editrush`) and, if the project has been
  saved to a file, to that file too. Save errors appear as a message at the bottom of the window.
- On launch, EditRush reopens the last session from the autosave, so quitting never loses work.
  Pending changes are flushed when you quit.
- Use **Save As…** (⇧⌘S) to give a project its own file. New Project and Open ask before
  discarding work that has never been saved to a file.
- A saved project is named after its file: renaming it (toolbar title or inspector) renames the
  `.editrush` file in the same folder. If a file with that name already exists there, the
  rename is refused and the old name stays.
- Double-clicking a `.editrush` file in Finder opens it in EditRush. Media files dropped on the
  Dock icon are imported into the current project. (Windows: the portable build has no file
  association yet; drop the file on `EditRush.exe` or use File > Open / Open Recent.)

## Windows

The Windows version has the same features and shortcuts, with these differences:

- Ctrl replaces ⌘ in every shortcut; Delete or Backspace replaces ⌫; Ctrl+Y also redoes.
- Colour filter presets approximate the Core Image looks; titles are drawn by the browser
  engine, so line spacing and shadows differ slightly.
- Export uses ffmpeg, with NVIDIA NVENC hardware encoding when available. Plain video and still
  stretches go straight through ffmpeg (about 9x real time for a 1440p capture at 1080p); fades,
  transforms, colour and filters are drawn by the preview's compositor (about 1.5-2x real time).
- Minimum timeline zoom is 0.5 px/s (macOS: 5) so Zoom to Fit can show long recordings.
- Projects saved on the Mac open on Windows, but Mac media paths show as Missing until relinked.
- `--snapshot` (below) is macOS only.

## Development notes

On macOS, `EditRush --snapshot out.png [--demo Fixtures] [--select-first] [--playhead 2] [--size 1600x1000]
[--wait 2] [--select-media 0] [--bin-add 0,1] [--status "message"] [--export-sheet]` renders the main window
(or the export sheet) offscreen to a PNG for UI checks without opening a window.
